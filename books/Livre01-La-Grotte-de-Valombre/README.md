# La Grotte de Valombre

Livre 01 de **Chroniques des Âges**.

## Illustrations

Dépose manuellement les illustrations dans :

`books/Livre01-La-Grotte-de-Valombre/images/`

Le livre cherche notamment des fichiers du type :

`La-Grotte-de-Valombre-001.jpg`

`La-Grotte-de-Valombre-002.jpg`

etc.

## Convention d’images

- JPG/JPEG : illustrations, présentation, portraits, objets, textures.
- PNG : uniquement pour les éléments nécessitant de la transparence, notamment les icônes de caractéristiques.

## Présentation de la bibliothèque

Ajoute :

`assets/presentation.jpg`
