# Modèle de livre

Duplique ce dossier pour créer un nouveau livre.

Garde la même structure et les mêmes noms d’assets.


## Convention d’images

- **JPG/JPEG** : illustrations de pages, image de présentation, portraits, objets, textures.
- **PNG** : uniquement pour les éléments qui nécessitent de la transparence, notamment les icônes de caractéristiques.

Noms standards :
- `assets/presentation.jpg`
- `assets/textures/texture-bouton.jpg`
- `assets/textures/texture-caracteristiques.jpg`
- `assets/textures/texture-parchemin.jpg`
- `assets/icons/vie.png`
- `assets/icons/dexterite.png`
- `assets/icons/force.png`
- `assets/icons/arme.png`
- `assets/icons/protection.png`
- `assets/icons/terre-noire.png`
